# paralela-proyecto

Para el proyecto es importante tener Maven, en caso de no, instalarlo y agregarlo a las variables de entorno.

## Ejecución

1. Ejecutar en cmd: `mvn clean compile`.

2. Lanzar nodos (por lo menos uno).

3. Ejecutar en cmd: `mvn javafx:run`.

* Si se realizan cambios en el codigo se debe volver a hacer el paso 1, si no se hacen cambios se puede ejecutar siguiendo el paso 3.

* El paso 2 no necesariamente va después del 1, solo debe hacerse antes que el 3 para la correcta ejecución del codigo.
